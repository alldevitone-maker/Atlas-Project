# @atlas/web

Shell React + Vite da aplicação final.

## Estado

O código está estruturado e os dados/configs de desenvolvimento estão presentes. O ambiente de build atual não possui acesso ao registry npm, portanto o lockfile e a compilação Vite devem ser gerados assim que houver conectividade.

O join territorial usado nesta fixture é deliberadamente o crosswalk nominal provisório do slice. Não é metodologia de produção.

## Instalação quando houver acesso ao registry

```bash
npm install
npm run build
```

Depois de instalar, o `package-lock.json` deve ser commitado.
