# Methodology

## Regra eleitoral

O Atlas descreve resultados associados a seções/locais de votação e unidades territoriais derivadas.

Nunca inferir residência ou comportamento individual.

## Source grain

Fonte primária eleitoral:
- seção eleitoral
- local de votação

## Analysis unit

- polling-place
- neighborhood

## Bairro

Quando usado, deve ser resultado de Crosswalk documentado.

## Comparação

Toda comparação deve passar por `ComparisonPolicy`.

## Confiabilidade

O limite mínimo deve ser tratado como critério de confiabilidade estatística, não como alegação de LGPD, salvo se houver base jurídica específica.

Nome recomendado no contrato:
`minReliableObservations`.
